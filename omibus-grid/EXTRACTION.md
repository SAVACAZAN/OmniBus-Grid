# Extraction notes

| Original source | New home | Decision |
| --- | --- | --- |
| `crates/omnibus-ui-tauri/src-tauri/src/grid.rs` | `crates/omibus-core/src/grid.rs` | Preserved linear/geometric spacing, market-side split, base/quote sizing and incremental sizing; added typed options, range/overflow validation, explicit reserve totals. |
| `crates/omnibus-core/src/types.rs` | Small typed domain in `grid.rs` and `paper.rs` | Kept only the grid order and wallet concepts needed here. Market scanner, candles, websocket and exchange-wide types were removed from this app. |
| `grid_bot_engine.rs` + `db/grid_bots.rs` | `crates/omibus-core/src/paper.rs` + `src-tauri/src/main.rs` | Replaced exchange placement with an isolated paper engine and atomic local file persistence. No live calls or API credentials. |
| Multiple Vue grid forms and the monolithic `App.vue` | `ui/` | Replaced with a single grid planning and bot management screen. |

The old exchange connectors, indicators, AI/MCP, scanner, market making, Telegram, backtest, and legacy UI crates are not dependencies. The old grid's pyramid, trailing and price-group execution modes are also not carried into this first app: their live fill, cancellation, and funds logic needs a separate design and tests. `Cargo.lock` should be generated by Cargo in a network-enabled Rust environment before release.

An unmodified reference copy of the original `omnibus-exchange` and `omnibus-core` crates is included under `future-live/crates/`. The active Cargo workspace does not include those crates. This preserves the connector source for later work without enabling network access or live orders in the paper app.

## Known issues found in the old live path

- Order rounding used nearest rounding despite its comment claiming to round down. This can exceed a balance or precision limit.
- The cancellation path could mark all local orders cancelled and stop the bot even when the exchange reported failed cancellations.
- The trailing path cancelled orders as a best effort, then placed a fresh grid without reconciling all cancellations.
- The live monitor used a short order history window and could miss fills for older active orders.

These are reasons this extraction has no live trading switch. They are not claims that any specific exchange account was affected.
